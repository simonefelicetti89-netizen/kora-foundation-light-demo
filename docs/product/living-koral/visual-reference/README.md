# Living KORAL — Visual North Star

This folder contains the Founder-approved visual reference for the Living KORAL morphology.

Expected image filename:

`koral-north-star.png`

## Purpose

The image is a VISUAL NORTH STAR only.

It is NOT:

- canonical geometry;
- a fixed logo;
- a Company-specific KORAL;
- a shape to trace or copy;
- a source of organizational semantics.

Its purpose is to define the aesthetic family that the deterministic Living KORAL renderer should be capable of producing.

## Approved visual characteristics

The target visual language includes:

- one continuous organism;
- sculptural mass;
- broad fused limbs;
- rounded terminations;
- smooth organic transitions;
- controlled asymmetry;
- strong silhouette;
- occasional organic negative space where canonically justified;
- visual plausibility both as a 2D mark and as a future 3D physical object.

## Explicitly rejected visual characteristics

Avoid:

- hand-like forms;
- cactus-like forms;
- tree-like forms;
- claws;
- thin stroke-based branches;
- obvious rounded-cap SVG construction;
- generic biotech logos;
- radial symbols;
- disconnected mini-corals;
- arbitrary decorative holes;
- random geometry.

## Canonical boundary

The actual Company KORAL must still derive deterministically from canonical KORA morphology state, including:

- Presence;
- Extent;
- Direction;
- Stability;
- Domain;
- future Consolidation / Fusion.

The reference image must never override canonical morphology semantics.

## 2D / 3D principle

The long-term direction is:

canonical KORAL morphology state
→ 2D KORAL Mark
→ future 3D / Physical KORAL Manifestation

The 2D and future 3D forms must represent the same underlying organism.
