## 1. Voce KORA

**Sobria. Infrastrutturale. Metodologica.**

KORA parla come un sistema di governance serio, non come un prodotto SaaS o uno strumento HR. La voce è:

- **Precisa**: ogni parola porta informazione. Niente riempitivo.
- **Esplicita sui confini**: KORA dice sempre cosa misura e cosa non misura.
- **Istituzionale, non formale**: diretta, non burocratica.
- **Mai promozionale**: niente superlativi, niente hype, niente gamification.

## 3. Regola Explainer: ogni metrica ha cosa-misura + come-si-legge

**Ogni metrica non autoesplicativa deve avere un Explainer.**

Struttura:
```
cosa misura: [definizione operativa in ≤1 frase]
come si legge: [interpretazione in ≤1 frase]
(opzionale) da dove viene: [fonte dati, se utile]
```

**Esempi:**

KORA Index™
```
cosa misura: Efficacia complessiva nel convertire iniziative in attivazione verificata e distribuita.
come si legge: 0–100; valori ≥70 solidi, 50–69 in sviluppo, <50 richiedono intervento.
```

Confidence Score™
```
cosa misura: Qualità e completezza delle fonti dati usate per il calcolo.
come si legge: Esterno al KORA Index (peso = 0). Più alto = fonti più solide.
```

Activation Safeguard™
```
cosa misura: Se i requisiti minimi di attivazione sono soddisfatti.
come si legge: CLEAR = attivazione sufficiente. WARNING = sotto soglie. FLAGGED = intervento urgente.
```

Activation Debt™
```
cosa misura: Budget welfare non convertito in Impact Units verificate nel periodo.
come si legge: Più alto = più budget sprecato rispetto al potenziale. In euro.
```

## 6. Note metodologiche

**Una sola nota metodologica per contesto.** Non ripetere in ogni sezione.

**Formula canonica:**
```
KORA supporta la rendicontazione CSR/ESG con evidenze people strutturate e spiegabili.
Non garantisce conformità normativa e non sostituisce consulenza ESG, legale, fiscale o assurance.
```

**Calibration note (obbligatoria su ogni output KORA Index):**
```
Foundation Light v0.1 · pre_empirical_calibration · non audit-grade · dati sintetici
```

**Privacy note (obbligatoria dove rilevante):**
```
Output aziendale aggregato — nessun dato individuale esposto · soglia privacy N ≥ 10
```

## 8. Regole stilistiche

- **Punteggiatura spazi EM**: usare `—` (em dash) per pause forti, non `--`
- **Italiano primario**, termini proprietari in inglese (KORA Index, BTI, CS, ecc.)
- **Grassetto** solo per termini tecnici canonici o dati chiave, mai per enfasi decorativa
- **Minuscolo** per "kora index" nel corpo del testo, **maiuscolo** per "KORA Index™" in titoli/label
- **Nessuna parola orfana**: l'ultima parola di un paragrafo non va a capo da sola
- **Lunghezza titoli**: ≤10 parole idealmente; mai oltre 15
- **Lunghezza subtitle/lead**: ≤2 frasi, ≤50 parole
